# Поток данных

1. **USER** вводит описание товара в WEB/MOBILE
2. Приложение (при необходимости) авторизует через **SUPABASE Auth**
3. Запрос уходит в **AI BACKEND** → `POST /api/classify`
4. Backend:
   - читает **ТН ВЭД базу**
   - применяет **Правила ОПИ**
   - подтягивает **Ставки**
   - AI анализирует товар → кандидаты кодов
5. При необходимости UI задаёт уточняющие вопросы
6. Пользователь подтверждает код + стоимость/вес
7. `POST /api/calculate` → пошлина + сбор + НДС + меры
8. **RESULT** — карточка «Таможенные платежи и налоги»
9. (Опционально) сохранение в Supabase `calc_history`
