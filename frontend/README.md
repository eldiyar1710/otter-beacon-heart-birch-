# Frontend — ТН ВЭД Калькулятор

## Запуск

Откройте `index.html` в браузере (двойной клик) или через локальный сервер:

```bash
npx serve .
# или
python -m http.server 8080
```

## Деплой

- **GitHub Pages:** Settings → Pages → Deploy from branch `main` / folder `/frontend`
- **Netlify / Vercel:** перетащите папку `frontend`
- **Любой хостинг:** залить `index.html`

## Возможности

- Калькулятор пошлин, сборов, НДС (₸ / ₽)
- AI-помощник
- Загрузка Excel базы ТН ВЭД
- Карточка «Таможенные платежи и налоги»
- Экспорт CSV

Полная база кодов: https://www.tws.by/tws/tnved/download
