# otter-beacon-heart-birch-

## ТН ВЭД Калькулятор + AI-помощник

Веб-приложение для подбора кодов ТН ВЭД ЕАЭС и расчёта таможенных платежей (пошлина, сбор, НДС).

### Файлы

| Файл | Описание |
|------|----------|
| `tnved_kalkulyator.html` | Основное приложение (открыть в браузере) |
| `TZ_TN_VED_Kalkulyator.md` | Техническое задание |
| `VSE_KODY_TN_VED.md` | Как получить все 13 000+ кодов |
| `convert_tnved.py` | Скрипт конвертации Excel → JSON |
| `tnved_demo_codes.csv` | Демо-коды (CSV) |
| `tnved_demo_codes.json` | Демо-коды (JSON) |

### Быстрый старт

1. Откройте `tnved_kalkulyator.html` в браузере
2. (Опционально) Скачайте полную базу: https://www.tws.by/tws/tnved/download
3. Вкладка «Загрузка Excel» → перетащите файл
4. Считайте платежи или используйте AI-помощник

### Возможности

- Калькулятор: пошлина + таможенный сбор + НДС
- Валюта: ₸ (Казахстан) / ₽ (Россия)
- Карточка результата «Таможенные платежи и налоги»
- AI-помощник: описание товара → код → расчёт
- Экспорт CSV / JSON
- Загрузка полной базы ТН ВЭД в браузере
